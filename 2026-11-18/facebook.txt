Téléphone volé : le voleur prend ton téléphone, mais le vrai danger, c'est ce qu'il ouvre. Cybersécurité du quotidien, à régler ce soir.

Dans ton téléphone, il y a ton WhatsApp, ton Mobile Money, ton e-mail.
Souvent aussi des photos de ta pièce d'identité.

Le problème qu'on ne voit pas :
Les codes reçus par SMS s'affichent souvent sur l'écran verrouillé.
Alors quelqu'un qui tient ton téléphone peut les lire sans connaître ton code.
Et si ton code Mobile Money est le même que celui de l'écran, une seule porte suffit.

Ce que tu vas comprendre ici : un vol de téléphone se prépare avant, pas après.

3 réglages de sécurité en ligne à faire ce soir :

1️⃣ Cache le contenu des notifications sur l'écran verrouillé.
Va dans Réglages, puis Notifications.
Choisis de masquer le contenu tant que le téléphone est verrouillé.
Un code reçu par SMS ne doit plus se lire sans déverrouiller.

2️⃣ Un code pour le téléphone, un autre pour l'argent.
Ton code Mobile Money ne doit être ni ton code d'écran, ni une date de naissance.
Deux codes différents = deux portes à forcer au lieu d'une.

3️⃣ Active la fonction Localiser.
Android : « Localiser mon appareil ». iPhone : « Localiser ».
Elle permet de verrouiller ou d'effacer ton téléphone à distance.
Vérifie ce soir qu'elle est bien activée.

Le code à connaître : tape *#06# sur ton clavier.
Le numéro IMEI de ton téléphone s'affiche.
Note-le sur papier ou hors du téléphone : il identifie ton appareil si tu dois le déclarer volé.
Source : Android (android.com, « Téléphone perdu : que faire ») ; ARCEP, « Que faire en cas de vol de mon téléphone mobile ».

Exemple : si on te vole ton téléphone, le réflexe dans l'ordre :
appelle ton opérateur pour bloquer la carte SIM, puis le service client de ton Mobile Money, puis verrouille l'appareil à distance.
Enregistre ces numéros ailleurs que dans ton téléphone, dès aujourd'hui.

✅ À faire aujourd'hui :
Cache tes notifications sur l'écran verrouillé.
2 minutes. C'est la porte que les voleurs trouvent ouverte.
