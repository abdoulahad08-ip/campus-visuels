Arnaque Mobile Money : le code reçu par SMS, personne ne doit te le demander. Même pas « ton opérateur ».

Le piège ne passe pas par ton téléphone. Il passe par ta confiance.
Une voix calme, un ton officiel, une urgence : et c'est toi qui donnes la clé.

Voici comment l'arnaque au faux agent fonctionne, et comment la casser en 30 secondes.

Exemple : Fatou, commerçante à Dakar. Un « agent » l'appelle : « Il y a une erreur sur ton compte. Tu vas recevoir un code, lis-le-moi pour la corriger. » Le SMS arrive. Elle lit le code. Quelques minutes plus tard, son compte est vide.

1⃣ Repère les 3 phrases d'alerte
« Ton compte va être bloqué. » → l'urgence pour t'empêcher de réfléchir.
« Donne-moi le code que tu viens de recevoir. » → ce code sert à valider une opération sur TON compte.
« Ne raccroche pas. » → pour t'empêcher de vérifier.
Une seule de ces phrases suffit : c'est une arnaque.

2⃣ Raccroche, puis vérifie toi-même
Rappelle le service client officiel, avec le numéro inscrit dans l'application officielle ou sur le site de l'opérateur.
Jamais le numéro qui t'a appelé, jamais un numéro donné par SMS.

3⃣ Fixe ta règle ce soir
Un code reçu par SMS ne se lit, ne se dicte et ne se transfère à personne.
Dis-le aussi à tes parents et à ceux qui gèrent ta boutique : ce sont souvent eux qu'on appelle.

La Police nationale du Sénégal a déjà alerté sur des campagnes d'arnaques visant les comptes Mobile Money. La seule parade sûre : le code ne sort jamais de ton téléphone.
