Arnaque Mobile Money : le code reçu par SMS ne se communique à personne. Même pas à un « agent » de l'opérateur.

L'arnaque au faux agent ne vise pas une faille technique. Elle vise la confiance, souvent celle des équipes : caissiers, gérants de boutique, assistants qui gèrent les paiements.

Le scénario : un appel au ton officiel, une « erreur sur le compte », puis la demande de lire le code qui vient d'arriver. Ce code valide une opération sur le compte. Une fois donné, l'argent part.

Trois réflexes à faire adopter dans votre entreprise :
1. Repérer les phrases d'alerte : urgence (« le compte va être bloqué »), demande de code, « ne raccrochez pas ».
2. Raccrocher et rappeler soi-même le service client officiel, jamais le numéro entrant.
3. Écrire la règle noir sur blanc : aucun code reçu par SMS ne se communique, à personne.

La Police nationale du Sénégal a alerté sur ces campagnes visant le Mobile Money. La parade la plus fiable reste une règle simple, connue de tous.
